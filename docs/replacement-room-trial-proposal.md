## Complete manual instructions to give before the test

These are proposed instructions, not controls available on the current live page. Supply the final deployed URL and exact control labels only after implementation and verification.

1. Open the protected test on the iPhone in Safari. Keep this chat silent and the test visible. Use a quiet room. Read the full instructions first.
2. Start the private test and allow microphone access if requested. Wait for the avatar and the page's ready indication.
3. Say: “I am going to a wedding in November. I like emerald green and a structured look.” Wait until the reply finishes. Confirm that the whole reply was heard using the page control.
4. Give a second short request. While the avatar is speaking, say: “Actually, I prefer blue.” The old audio must stop and stay stopped. The page should show cleanup and replacement progress; do not press Start again.
5. Wait for the replacement to become ready. If cleanup fails or the test ends, stop here and report the message. Do not restart.
6. Repeat the correction if prompted. The next answer should retain the confirmed wedding/November context and address blue. It must not assume that the interrupted assistant reply was heard.
7. End the test. Confirm sound stops, microphone use ends and the page reports verified connection cleanup. Do not refresh or start another test.
8. Report whether old audio ever returned, whether confirmed details were retained, whether the correction was understood, and whether End stopped sound and microphone use. Report any displayed error.
